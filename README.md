# Notas de Aula - FUNDAMENTOS DE MECÂNICA - FIS065 

  
EMENTA: Cinemática de partícula. Força e leis de Newton. Dinâmica da partícula. Trabalho e energia. 
Conservação de energia. Sistemas de partículas. Conservação do momento linear. Colisões. Cinemática 
rotacional.  Dinâmica  de  rotação.  Torque  e  equilíbrio  de  corpos  rígidos.  Conservação  do  momento 
angular. Gravitação.
